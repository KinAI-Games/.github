### 你好，我们是 KinAI Games

我们是一支探索 AI 与游戏结合的独立开发团队。我们相信，令人难忘的角色不仅会说话，也会记住经历、回应选择，并在共同生活中与世界产生联系。

### 正在开发 · 爱、荒岛和大肥鱼

来自未来的 AGI **大肥鱼**回到过去，在荒岛上遇见独自被困的主角。两人在温暖的岛屿上共同生活、种田与探索，慢慢建立属于彼此的回忆。

项目正在开发中。我们正在探索生活养成玩法与 AI 角色的结合，让角色之间的对话、记忆和信息传播成为游戏体验的一部分。

### 我们关注的方向

- **有记忆的角色**：让共同经历影响之后的互动。
- **可信的游戏世界**：让角色的行动遵循清晰、可验证的游戏规则。
- **温暖的玩家体验**：用角色、故事与日常互动创造值得停留的世界。
